# Archived Execution Plans

This directory holds execution plans that have been **frozen out of the current product scope**.

Plans are moved here when:

- the product scope narrows and the plan's work is no longer in the active delivery target
- the plan is superseded by a new direction but preserved for reference
- the work may re-enter scope in a future release but is not committed to the current roadmap

Archived plans are **not active instructions**. They are preserved as context for why certain capabilities exist as design material without being part of the current delivery scope.
