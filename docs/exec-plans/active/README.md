# Active Execution Plans

Put in-progress execution plans here.

A good active plan should answer:
- what problem is being solved
- what constraints must be preserved
- what the next concrete implementation steps are
- how the work will be verified

When the work lands or is abandoned, move or rewrite the plan instead of leaving stale instructions behind.
